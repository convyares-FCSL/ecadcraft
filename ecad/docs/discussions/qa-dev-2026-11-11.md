### The three failures (deterministic: each fails the same way on a rerun)

1. `cable_slash_acceptance_contracts::ac8_max_cable_members_is_the_cap`
2. `cable_slash_acceptance_contracts::r2_cableadd_cap_holds_for_the_whole_cable`

   ```
   panicked at crates\ecad-cadcraft\tests\all\cable_slash_acceptance_contracts.rs:930:26:
   unexpected op in a wire transaction: SetProperty { object: Conductor(cnd-95872c87), key: "wire_number", before: None, after: Some("01") }
   ```

   - **Cause:** the test helper `bulk_wires` copies the ops of one real `wire` transaction and
     panics on any op it does not know. Since brief 022, `wire` also records the new wire's
     `wire_number`.
   - **Tried:** skipping `SetProperty` in the copy. Both tests then pass.
   - **The fix belongs in the test helper:** copy the property onto the new conductor, or skip it.

3. `tester_014_r3_scope_probe::tester_014_r3_random_edits_across_two_pages_match_the_oracle`

   ```
   panicked at crates\ecad-cadcraft\tests\all\tester_014_r3_scope_probe.rs:235:17:
   step 0 (drag one end): reference text "2-A-6"
   ```

   - **Cause:** the probe's `well_formed` still expects the old `/2.1` reference form. Brief 019
     made it `page-column-row`.
   - **Tried:** accepting that form. The probe then passes the whole random-edit oracle run
     (movement and `translate.rs` across two pages).
   - **Until it is fixed:** the probe stops at step 0, so this oracle has not covered movement
     since 019 merged.

**Worth a look (not a failure):** these three took far longer than their `#[ignore]` reasons say.

op or text format changed.

## 4. Owner's trial checklist (one sitting, about 45 minutes)

Start from a fresh demo: run `cargo xtask demo --force`, which replaces
`C:\dev\ecad-projects\demo.ecad`. Then open it:
`cargo run --release -p ecad-trial -- C:\dev\ecad-projects\demo.ecad`. Section numbers are
`docs/quick-start.md`.

1. **Project panel (5E, 016).** Switch between pages. Add a page with **+** and rename it by
   double-click. Drag it to reorder. Draw a wire on one page, show another and type `u`: the
   first page comes to the front with the wire gone.
2. **Preview a reference (5E step 8).** On page 2, click `-W01`'s reference point, then
   **Preview Reference**. A read-only window shows page 3 with a magenta ring. Close it.
3. **Devices (5F, 5G, 018).**
   - Place a coil as a new device with **Find Symbol**.
   - Place a NO contact that joins it by clicking its `-K…` line.
   - Rename it to `K5` in **Device Properties**: every symbol follows. Then `u`.
   - In the **Devices** tab, click a symbol row: its page is shown and the symbol selected.
4. **Sheets (5H steps 1–4, 019).**
   - The A3 frame shows `A`–`H` and `1`–`6`.
   - References read `3-C-4` and `2-C-5`.
   - Number page 2 as `105`: the title block and page 3's reference follow. Then `u`.
   - **Project info**: fill it in, then OK. One `u` takes it all back.
5. **Revision (5H steps 6–8).** Issue Rev A and save. Draw a wire. **Reopen** Rev A shows the
   page without the wire. Then **Back to current**. Undo twice: it asks before undoing the issue.
6. **Wire numbers (5I steps 1–4, 022).**
   - Page 2's labels look like `24V-04 0.5 BU`, and no two touch.
   - Hover the 0V wire: its net lists 5 wires.
   - Draw from the lamp's `X1`: the new wire is `24V-04`.
   - Draw a free wire with **Potential** `24V`: it gets the next free `24V-…` number.
7. **Junctions and checks (5I steps 5 and 7).**
   - End a wire on another wire's middle: a dot appears.
   - Erase the dot. **Checks** now shows `Looks connected, no junction`.
   - Click **Add junction**: the dot is back.
   - Click the `-M01:PE` row: page 3 is shown, centred on it.
8. **History and a branch (5J steps 1–4, 020a).**
   - Save. In **History**, create the version `Before change` and save.
   - **Branch from here…** `Option B`: the title ends `· Option B`.
   - Change `-K01`'s description.
   - Switch to `main` and choose **Save and switch**: main's description is unchanged.
9. **Restore (5J step 6).** On main, draw two wires. Restore `Before change`: it says
   `2 objects change`, the wires go, and `u` brings them back.
10. **Merge with a conflict (5J steps 10–11, 020b).**
    - Set `-K01`'s description differently on a branch and on main, then **Merge into main…**.
    - The dialog shows `1 conflict` and **Merge** is disabled until you choose. Choose
      **Keep branch**, then **Merge**.
    - Press `u`: it asks `Undo the merge?`.
11. **Save, close, reopen (7 and 5J step 8).**
    - Close with unsaved changes: Save, Discard and Cancel all work.
    - Reopen: it opens on the branch you were on, with the same History graph and the same wire
      numbers.
12. **Container v2 (7 step 8, 7B, 7C, 021).**
    - Make an edit, then end the trial from Task Manager. Reopen: the leftover lock is reclaimed
      and the unsaved edit is gone.
    - Open `C:\dev\ecad-projects\demo-old.ecad` (version 1): it offers **Convert and open**.
    - `ecadinspect <file> verify` says `everything verifies`.

The 023 sync has no step of its own. Its visible effects are covered in passing: the window
