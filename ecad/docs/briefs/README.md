# Open briefs

Work not started or in progress: release briefs, briefs with their design specs, and draft briefs for work
put off. Each says its status and, where one is set, its release. The [roadmap](../roadmap.md) has one line
per item pointing here. A brief is approved before work starts; when the work is done its still-true facts
go into the current docs and the brief moves to the [archive](../archive/README.md). Draft briefs are named
by topic; a brief gets a number when it is approved.
