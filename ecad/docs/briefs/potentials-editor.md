# A potentials editor in the app

Status: Draft, not started; release not yet placed

## What

A view of the potentials table (name, prefix, numbered, supply) in project settings. Today the table is set
only with `wiresettings`; no settings sheet shows potentials, so the supply cannot simply be a column of an
existing view.

## Also look at

The project defaults `rating.voltage` and `rating.system` (the volt-drop calculation's supply) overlap with the
supply typed on a potential; decide whether the volt-drop calculation reads the circuit's potential instead.
