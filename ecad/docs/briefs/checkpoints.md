# Checkpoints and "Save a Copy As"

Status: Draft, on hold until libraries and the core domain features are settled

## Checkpoints

Faster opening of long histories. On the benchmark's large tier, about 13 s to open 170,000 transactions is
acceptable for now. Libraries (`.ecadlib`) and their interface are planned separately (see the
[roadmap](../roadmap.md)); checkpoints must not be built before they are approved.

## Save a Copy As

"Save a Copy As" writes a copy of the project with a new project ID.
