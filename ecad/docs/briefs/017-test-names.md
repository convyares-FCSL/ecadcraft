# Brief 017: test names before and after

Acceptance criterion 1 of [brief 017](017-fast-tests.md): every test that ran before still runs,
with the same name and result, in the fast default or in the slow set.

How these lists were made: `cargo test --workspace --all-features -- --list` (and `--ignored`)
at the base commit `738a311` (before) and on `feature/fast-tests` after the review fix round
(after), on Windows. An integration test's name before was `<test>` in the executable
`tests/<file>.rs`; after, it is `<file>::<test>` in the crate's one executable `tests/all/main.rs`
(target `all`). Unit tests (`unit`) and doc tests (`doc`) keep their names. `ecad-store`'s
`disk_contracts` and `ecad-bench`'s `translate_differential` keep their own executables.

| | Before | After |
| --- | --- | --- |
| Tests | 563 | 565 |
| Ignored | 8 (child-process helpers) | 20 (8 helpers, 12 slow) |
| Test executables (unit, integration) | 70 | 20 |

Diff of the names, mapped one to one: none lost, none renamed beyond the module prefix. Added: two
tests of `cargo xtask test-changed`, `ecad_xtask` `tests::test_changed_on_this_workspace` and
`tests::test_changed_picks_changed_crates_and_their_dependents`.

Set: **fast** runs in `cargo test` and `cargo xtask test-changed`; **slow** is
`#[ignore = "slow: …"]`; **child** is a helper its own test starts in a child process (ignored
before and after). The QA gate (`cargo xtask ci`) runs all three with `--include-ignored`.
