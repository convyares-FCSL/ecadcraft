## Goal

What every stored object is, and how it relates to other objects, is held in its own typed struct,
never worked out from names, symbols, strings or positions (owner, 2026-11-16). Code review
2026-11, findings 4, 6, 7 and 10, widened to the whole store.

## The rules every lane follows (design Part I)

- Data, not inference: no predicate walks to a symbol, no name matching, no cached guesses.
- One struct per object type; kind-specific data in enum variants.
- Shared behaviour as traits; each type owns its calculations as methods; checks and reports call
  them and never recalculate.
- Relationships stored as IDs, at the level they belong.
- Strict words: an unknown word or field in a file is a read error and the project opens read-only
  (damaged-records path); the file is never changed.
- No compatibility code: fixtures and test files are regenerated by the code that made them; no
  shims, no converting reader.
- Every guard of design §11 that the lane owns ends at 0 with no allowlist.
- The inspector's Raw and Readable views show every new struct, field and op (hard rule, A15).
- Every command whose input or recorded op changes keeps working through `ecad-mcp` with the brief
  011 contract test.

## Steps inside each lane

Each step is one or more commits `072<lane> <step>: …`, each green: builds, clippy clean, tests of
the crates it touched pass, every guard at or under its count. Push after each green commit.

**A1.** (1) strum, `words.rs`, `units.rs` with their tests (A1). (2) `keys.rs`: `PropKey`, `Area`,
`KEYS`, `FAMILIES`, `RESERVED`, `PropsExt` (A3). (3) `Word` and its macro; `StyleCatalogue`, `Side`,
`PageColumn`/`PageRow`/`PageNo` (A2). (4) After 070's ecad-file batch: unknown typed words as
damaged records, `ReadOnly::UnknownWords`, `words_check` hook (A4, A15). (5) Guards as ratchets at
their exact counts (in the commit message).

**A2.** One area per commit: identity and tag; book and page keys; connectivity and wiring; BOM;
rating circuit keys; revisions and designations; front; text and symbol families; then defaults
(`Kind::Flag`, `Choice<E>`, TOML regenerated with `yes`/`no`, the Standards switches); units
(`rating/parse.rs`, stored angles, command degrees, `Value::Length`, `Grid`/`Place`); small enums
and `StarterKey` with its 11 exhaustive match blocks. **Stop and report** after the first two areas
so the overseer can check the pattern. Ends with G1 (for literals), G2, G3, G7, G8, G9 at 0.

**B.** (1) The device struct, `DeviceType` with every group's struct (empty where its lane fills
it), `ModifyDevice` with its contract tests, symbols declaring their type, placement setting it:
**merge this step** so C can start. (2) Common fields and part lines out of the bag. (3) One group
per commit: Protection, Relay, Switch, Sensor, Motor, Solenoid, Indicator, Heater, Psu,
TerminalStrip (with `PointKey::Level`, jumpers, accessories), Connector (`PointKey::Side`): fields
into the variant, the trait methods implemented, readers and commands moved, keys to `RESERVED`.
(4) `PartRole`/`Role`, `SlotText`, `SymbolDefaults`. (5) User fields, device links. (6) The oracle
test A7 has recorded today's predicate answers since step 1; now the predicates go (G6).

**C.** (1) `PlcRack`, `PlcModule`, channel groups; today's CPU/head-module cards become a rack plus
a CPU module (fixtures regenerated). (2) Addresses, I/O list and rack overview as methods. (3)
`PointKey::Channel`; `body_type`, `of_body`, `is_rack` go.

**D.** (1) The wire struct and `ModifyWire`. (2) The cable struct, cores folding members,
`ModifyCable`. (3) `Circuit` and the rating and volt-drop methods; the checks call them (A10).

**E.** (1) `Page`/`PageKind`, `ModifyPage`. (2) `Project`, revisions, designations, `ModifyProject`;
function and location as entry ids on pages (devices take them in B or after, whichever lands
second). (3) `Folder.start`. (4) Title block strictness (G10's title block part to 0).

**F.** (1) `Attach::Wire` and junctionless nets (A12; `translate.rs`, so the tester covers
movement). (2) Drawing aids, `Subject::Aid`, `TerminalOwner::Aid`. (3) Boxes setting location
(A13). (4) Loose parts per the owner's call. Ends with G4, G6, G11, G12 at 0: every guard is now a
ban.

**G.** One catalogue per commit.

## Stop and ask the overseer

- A device whose new group differs from what today's predicates imply (A7).
- A field that turns out to belong to more than one group, or a holder the design didn't list.
- A drawn form (`Form::Drawn`) that needs its starter, which the role no longer carries.
- Any stored field, word or op not in design §10.
- A guard that can't reach 0 without a change outside the lane.

--all-targets --all-features -- -D warnings`. Long output to a log file under
