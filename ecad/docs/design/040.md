# Design 040: the canvas (U4a), tokens and choices made while building

Brief: [`040-ui-canvas.md`](../briefs/040-ui-canvas.md). The look is the spec's §4 ("Canvas
colours", "Type", "Line weights") through `ecad-tokens`; this file records only what the lane
added or decided while drawing. Its token section moves to `tokens.md` at the phase-end tidy-up.

## 1. Choices

| What | Choice | Why |
| --- | --- | --- |
| Sheet colour | CADCraft's model background = `sheet.sheet`; selection colour = `sheet.selection` | The existing drawing-area preferences (design §1.5): no seam |
| Ink on screen | CADCraft draws colour 7 as `#000000` on a light background, not `ink` `#16191D` | Matching exactly needs an upstream seam; open point |
| Around the sheet | The shell's `bg` at 88 % outside the sheet frame, with the one shadow (0 8 24 px, black 45 %) outside it only | The page reads as paper on a desk; geometry outside the frame still shows faintly |
| Dot grid | ECAD paints 0.25 mm dots every 5 mm from the sheet's lower left corner, inside the frame, only when the pitch is at least 10 px and at most 20 000 dots show | Painted over the drawing (egui cannot paint under CADCraft's background), so it is kept sparse; a dot can sit on a wire (open point) |
| Error, warning | Painted: a 12 px filled disc / triangle with a white "!" | `ext::MarkShape` has ring, dot and square only; no new upstream variant (design §1.5) |
| Orphan reference, looks connected | Were red / yellow rings (`ext::Mark`); now the painted error disc / warning triangle | Spec shapes by meaning |
| Connection point, attached end, loose end | `ext::Mark` ring 8 px, dot 5 px, square 7 px in the token colours | Spec sizes (were 8, 4, 6 px) |
| Cable crossing dot, linked reference ring | `ext::Mark` in `sheet.cable` | Cable meaning |
| Provisional tag | Dotted underline in `sheet.provisional` under the tag's text | "Dotted means not final yet"; the text colour is still 026's ACI |
| Related placements | Dashed outline, selection colour, 3 px clear of the placement's drawn handles | Spec: other placements of the same device get a dashed outline |
| Wire colours | Ink, drawn by the page's projection (`wires::colour_routes`, one call in `project_page_framed`; overseer 2026-11-13, option B): the route entity takes the first colour as true colour, a two-colour code adds the second colour's dashes as lines on `ECAD-WIRE-COLOUR`, mapped to the conductor like its label (left out of an edit with other objects, refused alone). Picking a dash selects the wire (`look::pick_routes`, done by the trial). The colours are the sheet's in use; `canvassheet {dark}` redraws the open page on a switch | One source for screen and print; correct layering under grips and picking |
| Wire colours in print | `print.colour colour`: the page projected for paper (`look::with_paper`), the wire colours and dashes kept, everything else ink (ACI 7); `mono` (default): the wires in ink, the dashes left out, the colour code already in the wire label | Owner answer 1 |
| Unknown colour code | Drawn in ink; one information check per conductor, `unknown-colour`, "Colour code not defined (drawn in ink); define it in Standards" | Spec; the button is the row's go-to until 042's Standards exists |
| Dash budget | At most 20 000 dashes a page (`look::MAX_PAGE_DASHES`) and 4 000 a wire (`MAX_DASHES`), in route order (`look::dash_budget`, read by the projection, the page check and Checks alike). A wire past the budget keeps its first colour; Checks shows one warning per page, `dashes-left-out`, "Two-colour wires drawn in one colour (too many dashes on the page)" | Review of PR #80: a hostile file could ask for 80 million dash entities |
| Sheet font registration | `ecad_cadcraft::install` registers Barlow Semi Condensed (and `printbook::print` makes sure), so the window, `ecad-mcp`, Print Book and release all draw in it; the bytes are embedded once, in `ecad-tokens::sheet_font`, and shared with `ecad-ui` | Review of PR #80: headless prints used another font |
| Two-colour codes | `GNYE`, `GN/YE`, `GN-YE`, `GRN/YEL`, `GRNYEL` and any pair of known codes (`RDBU`, `YEBN`) | Spec |
| Sheet font | `text.font` built-in `Barlow Semi Condensed`; fallback `BIZ UDPGothic`, then the stroke font; bold is the family's Bold, else its SemiBold | Spec §4 "Type"; 031's chain kept as the fallback |
| Cap heights | Values unchanged; labels say "cap height"; `textstyle` returns `height_is: "cap height"` | CADCraft draws a text height as its cap height (measured by test) |
| First-open zoom | A page opened for the first time (no stored view) opens where a tag is 13 px tall; 038 remembers the view after | Spec §4 |
| Leader line | 1 s, fading, selection colour, from the companion's edge to the selected objects | Spec §5; from the companion's edge, not the row (the table does not expose row rectangles) |
